เส้นตัดเส้นพับเส้นมาร์ก/ม้วนกรอบหน้า A3

พิมพ์แบบตัดขนาดจริง (1:1) บน A3

  1. Export PDF แล้วสั่งพิมพ์ A3 ที่ 100% / Actual size — ห้ามเลือก Fit to page
  2. วัดแถบสเกล 100 มม. ที่ขอบล่างทุกหน้า ถ้าไม่ได้ 100 มม. ให้ตั้งเครื่องพิมพ์ใหม่
  3. เรียงหน้าตามรหัส แถว A, B, C… / คอลัมน์ 1, 2, 3… (เช่น P1-A1, P1-A2) ตามภาพรวมหน้าแรก
  4. ตัดกระดาษหน้าขวา/ล่างตามกรอบเส้นประด้าน ซ้ายและบน แล้ววางทับหน้าก่อนหน้า ให้เครื่องหมาย + ในแถบทับซ้อนตรงกัน ติดเทป
  5. วางแบบบนแผ่นเหล็ก ตอก/ขีดตามเส้นตัด เส้นพับ (เส้นประน้ำเงิน) และเส้นมาร์ก (สำหรับม้วน/พับเป็นจังหวะ)

ขนาดคลี่คิดที่ กลางเนื้อ (Neutral) ตามความหนา — ตั้งได้ว่า D/ขนาดที่ป้อนเป็นขนาดภายใน ภายนอก หรือกลางเนื้อ · งานพับคิด Bend allowance จาก K-factor
